Razi: doubt, measure, record

Ask a design question in plain English. Razi runs the twin, searches for better layouts, checks results against written requirements and writes an evidence-backed memo. Its safety does not depend on the model behaving well.

System 03 · Platform

Production engineering, not a notebook

  • AG-1 campaign designer: a LangGraph agent drafts experiment campaigns, dry-runs them through the compiler and stops for scientist approval
  • Zero-cost prototyping: every model call goes through a LiteLLM gateway; I prototype on Llama running locally in Ollama, so there is no API cost and no data leaves the machine. Moving to an enterprise model is a config change, and the gateway routes each request by data sensitivity.
  • Formulation compiler: deterministic, typed and versioned, with property-based tests, a 250-case corpus, schema-compatibility checks and security scans in CI
  • Simulation first: every device has a simulated twin with the same API; robot routes mature from twin-verified to hardware-verified with human approval

System 04 · Implementation blueprint

The whole cell, designed end to end in one specification

My V3.1 implementation specification turns the lab into a buildable, verifiable system, with 20 architecture decisions, typed contracts, a delivery roadmap and acceptance tests. Its rule: MADSci executes, sdl_dt thinks, agents assist, ROS 2 moves, the safety system protects.

  • 10-stage pipeline: specify → compile → schedule (OR-Tools CP-SAT) → reserve → validate in the twin → approve → per-action execution gate → execute → verify → learn
  • Agentic layer: five LangGraph agents behind one MCP tool server and a LiteLLM gateway (local Ollama models for zero-cost prototyping), with evaluation-gated CI. No tool reaches hardware, approvals or safety configuration.
  • Constrained multi-objective BO: BoTorch / Ax with qNEHVI, a feasibility classifier and the compiler dry run as a manufacturability constraint
  • Delivery: 18 acceptance tests, 7 commissioning and safety gates, a 6-milestone roadmap
